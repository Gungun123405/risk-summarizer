# Client Risk Summarizer

A text analytics pipeline that classifies news articles by category, generates risk-focused summaries using an LLM, and extracts key entities (organizations, monetary values, percentages, dates) — built to explore practical applications of classification, prompt engineering, and information extraction for client risk monitoring use cases.

## What it does

Given a news article, the pipeline:
1. **Classifies** it into a category (business, politics, sport, tech, entertainment) using a TF-IDF + Logistic Regression model
2. **Summarizes** it with a 2-sentence risk-focused summary, generated by an LLM with a purpose-tested prompt
3. **Extracts entities** (organizations, monetary values, percentages, dates) using spaCy's NER model
4. Returns the result as structured JSON via a FastAPI backend, displayed through a React frontend

## Why this project

Built to explore the intersection of classification, LLM-based text analytics, and information extraction — directly relevant to research and risk-monitoring workflows in a consulting context.

## Tech stack

- **Classification**: scikit-learn (TF-IDF, Logistic Regression)
- **Summarization**: Groq API (LLM inference)
- **Entity extraction**: spaCy (`en_core_web_sm`)
- **Backend**: FastAPI
- **Frontend**: React (Vite)
- **Data**: BBC News Archive (2225 articles) + HuffPost News Category Dataset (filtered to ~68K matching articles)

## A real problem I found and fixed

The initial model, trained only on the BBC News dataset (2225 UK articles from the 2000s), misclassified a 2026 Indian political article ("BJP releases list of Rajya Sabha candidates...") as "business" — a clear domain shift failure, since the model had never seen Indian politics or modern political vocabulary.

**Fix**: combined the BBC dataset with the HuffPost News Category Dataset (68K+ articles across matching categories), added `class_weight="balanced"` to handle the resulting class imbalance, and retrained. Accuracy on this harder, more diverse task came out to 87% (down from 96.9% on the narrower BBC-only task, which is expected given the increased diversity) — and the specific misclassification was fixed. Also added a confidence threshold so the model returns "Uncertain / Out-of-domain" rather than forcing a low-confidence guess.
